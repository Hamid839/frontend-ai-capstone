### Selected claim

## 2. Content map

**Primary journey:** Home → Work → Case study → Contact

### Home (`/`)

**Purpose:** State the claim quickly and send visitors to evidence.

**Sections in order:**

1. Hero — name, positioning, one-line claim
2. Primary CTA: **Explore My Work** · Secondary CTA: **About Me**
3. Proof points — responsive interfaces; features connected to data/APIs; debugging and iteration
4. Featured project — **MedNoviAI** (strongest case leads)
5. Additional work teaser — FocusBoard + workflow evidence
6. Closing CTA: **Get in Touch**

### Work (`/work`)

**Purpose:** Overview of practical experience; strongest work first.

**Sections in order:**

1. Short introduction
2. Featured case: **MedNoviAI** (patient-side / appointments contribution)
3. **FocusBoard** (AI-assisted React task planner)
4. Additional verified work (Settings Form drill / prompting evidence if useful)
5. CTA: **Discuss My Work** → `/contact`

Each card: project name · problem · my contribution · stack · link to case or demo.

### Case study (section or `/work/[project]`)

**Purpose:** Show how I approach real frontend requirements.

**Sections in order:**

1. Context and problem
2. User need and implementation goal
3. My specific contribution
4. Real screenshots of the implemented feature
5. Technical decisions and data/API integration
6. Challenge and how I addressed it
7. Verification, limitations, lessons
8. CTA: **Explore More Work** → `/work` or **Get in Touch** → `/contact`

### About (`/about`)

**Purpose:** Background and working approach.

**Sections in order:**

1. Short introduction
2. Learning journey / education
3. Frontend skills and technologies
4. Internship and team-project experience
5. AI-assisted development approach: suggest → review → verify
6. CTA: **Explore My Work** → `/work`

### Contact (`/contact`)

**Purpose:** Make the one action easy. Also in header and footer.

**Sections in order:**

1. One sentence on openness to junior frontend roles
2. Verified email, GitHub, LinkedIn
3. CTA: **Get in Touch** (email / LinkedIn)
