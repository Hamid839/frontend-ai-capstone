# frontend-ai-capstone

Capstone project for the FlyRank Frontend AI Engineering Internship.

## Settings page

Open `index.html` in a browser to use the responsive settings form. It includes editable name and email fields, light/dark/system theme selection, and an email notifications toggle. Preferences are stored locally in the browser when you save.

The page is dependency-free and uses plain HTML, CSS, and JavaScript so it can run without a build step.
