# Case Study 1: MedNoviAI — Patient-Side Experience

**Project:** MedNoviAI — AI Healthcare Assistant & Smart Appointment Platform  
**Role:** Frontend development intern / contributor  
**Technologies:** Next.js 16, TypeScript, Tailwind CSS, Supabase  
**Audience:** Technical hiring managers evaluating junior frontend developers

## 1. The Problem

MedNoviAI is a healthcare platform designed to help patients interact with healthcare services online. The patient experience needs to make appointment information accessible and allow patients to manage their appointments without unnecessary confusion.

My work focused on the patient side of the platform. One important part of this work was connecting the frontend to Supabase so the application could work with real backend data instead of relying only on static interface elements.

## 2. What I Did and What I Decided

I contributed to patient-side features using Next.js, TypeScript, Tailwind CSS, and Supabase. My work involved integrating the frontend with Supabase and working within the project's existing structure.

Connecting the frontend to Supabase was the biggest technical challenge I faced during implementation. I initially found this part challenging, but I was able to understand the integration and resolve the difficulty as I progressed.

This experience helped me become more comfortable working across the frontend and backend boundary. It also reinforced the importance of understanding how application data is accessed and connected to the user interface, rather than treating the frontend as a separate layer.

I worked within an existing team project, so this case study represents my contribution to the patient side rather than claiming that I built the entire platform independently.

## 3. What Came of It

I gained practical experience connecting a Next.js frontend to Supabase and contributing to a real healthcare application. I also learned to approach unfamiliar integration work by understanding the existing project and working through the technical problem.

The most valuable part of this experience was moving beyond interface development and becoming more comfortable with the data integration that makes a frontend feature functional.

**What I can demonstrate:** My contribution to the patient-side code, the relevant implementation, and the changes I made during the project.
